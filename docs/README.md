# ILDS Docs Index

This folder is the canonical home for process and project docs.

Current root-level operational docs can be gradually moved here without breaking
automation, as long as command/script references are updated if needed.

Recommended structure:

- `docs/briefs/` — build briefs and implementation plans
- `docs/reports/` — status reports, postmortems, handoff notes
- `docs/runbooks/` — operational runbooks (token sync, release flow, CI recovery)

Until migration is complete, existing root docs remain valid.
